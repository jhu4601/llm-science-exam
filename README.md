# LLM Science Exam — Multiple Choice Question Answering
**Kaggle LLM Science Exam Competition** | NLP / Large Language Model Fine-Tuning

## Overview
Fine-tuned DeBERTa-v3-large to answer science multiple-choice questions
generated by GPT-4. Extended the training set from 200 to 700 examples
using additional data, and implemented KFold cross-validation for robust
model evaluation.

## Approach
- **Data augmentation** — expanded training set from 200 to 700 examples
  by merging additional science exam samples
- **Tokenization** using DeBERTa-v3-large tokenizer (Hugging Face)
- **Model** — fine-tuned `AutoModelForMultipleChoice` on DeBERTa-v3-large
- **Cross-validation** — KFold CV to reduce overfitting on small dataset
- **TF-IDF retrieval** for context augmentation
- **Training** via Hugging Face Trainer API with EarlyStoppingCallback
- **Evaluation metric:** Mean Average Precision @ 3 (MAP@3)

## Tools Used
Python (Hugging Face Transformers, PyTorch, scikit-learn, datasets,
pandas, numpy)
